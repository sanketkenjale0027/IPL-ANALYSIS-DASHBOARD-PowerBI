# 🏏 IPL Analysis Dashboard (2008–2025)

## 📊 Project Overview

The **IPL Analysis Dashboard** is an interactive **Power BI dashboard** developed to analyze and visualize Indian Premier League data from **2008 to 2025**.

The dashboard provides insights into team performance, player statistics, points tables, and key IPL season metrics through interactive visualizations and filters.

## 🛠️ Tools & Technologies

* **Power BI**
* **Power Query**
* **DAX**
* **Excel / CSV**
* **Data Visualization**

## 📌 Key Features

* 🏆 Champion and Runner-up analysis
* 📊 Interactive IPL Points Table
* 🏏 Total Matches and Teams
* 4️⃣ Total Fours and Sixes
* 💯 Half-Centuries and Centuries
* 🟠 Orange Cap statistics
* 🟣 Purple Cap statistics
* 👤 Player performance analysis
* 🔍 Interactive IPL Season filter
* 📈 Team-wise Wins, Losses, Ties, No Results and Points
* 🏟️ Season-wise venue statistics

## 📈 Key Insights

The dashboard enables analysis of:

* Season-wise IPL champions and runners-up
* Top-performing batsmen and bowlers
* Orange Cap and Purple Cap performances
* Team wins, losses and total points
* Batting statistics including fours, sixes, half-centuries and centuries
* Overall IPL season performance
